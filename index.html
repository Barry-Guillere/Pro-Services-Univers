☁️ Synchronisation Cloud (base de données partagée)
Non configuré
Les saisies de tous les comptes (PDG, Production, Finance, Stock, Logistique) sont partagées en temps réel, sur tous les appareils, via votre session déjà connectée — aucune clé à saisir ici : elle est gérée côté serveur (Edge Function cloud-sync), jamais dans le navigateur.
Mise en place côté serveur (une seule fois, par l'administrateur)
1. Dans le projet Supabase (le même que celui utilisé pour la connexion) : SQL Editor, colle le contenu de schema_supabase.sql (une table par module : Finance, Stock, Commerce, Logistique, Points de vente, Sanitaire, Paramètres) puis clique "Run".
2. Edge Functions → New function → nom cloud-sync → colle le contenu de supabase/functions/cloud-sync/index.ts → Deploy.
3. Sur cette fonction : Settings → "Verify JWT with legacy secret" = désactivé (la vérification se fait déjà dans le code, via la session de l'utilisateur).
4. Important — sécurité : exécute aussi schema_cloud_sync_lockdown.sql dans le SQL Editor. Il verrouille ces tables (RLS) pour qu'elles ne soient plus accessibles qu'à cette Edge Function, même par quelqu'un qui aurait la clé publique du projet.
5. Rien d'autre à configurer : chaque compte de l'équipe synchronise automatiquement dès qu'il est connecté.
